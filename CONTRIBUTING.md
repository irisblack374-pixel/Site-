# Contributing

Thanks for helping improve Site-.

## Before you start

1. Read the README.
2. Do not commit `.env`, tokens, passwords, or private credentials.
3. Keep changes focused and explain what changed.
4. Test the bot locally before opening a pull request.

## Development

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the bot:

```bash
python bot.py
```

## Pull requests

Include:
- What changed
- Why it changed
- How you tested it
- Any limitations or follow-up work
