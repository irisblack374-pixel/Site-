# Site- Documentation

## Quick Start

```bash
pip install -r requirements.txt
```

Create `.env`:

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
```

Run:

```bash
python bot.py
```

## Commands

- `/ping` — bot latency
- `/server` — server information
- `/user` — member information
- `/avatar` — member avatar
- `/help` — command list
- `/clear` — delete messages
- `/kick` — kick a member
- `/ban` — ban a member
- `/unban` — unban by user ID

See the main README for the complete beginner setup and troubleshooting guide.
