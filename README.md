# Discord Bot

بوت Discord بسيط باستخدام Python و discord.py.

## التشغيل

1. ثبّت Python 3.11 أو أحدث.
2. ثبّت المتطلبات:
   pip install -r requirements.txt
3. انسخ .env.example إلى .env.
4. ضع توكن البوت داخل:
   DISCORD_TOKEN=YOUR_BOT_TOKEN
5. شغّل:
   python bot.py

## الأوامر

- /ping
- /server
- /user
- /avatar
- /help

لا ترفع ملف .env إلى GitHub.
