## 🚀 Run

Install the requirements:

```bash
pip install -r requirements.txt
```

Create `.env`:

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
```

Start the bot:

```bash
python bot.py
```

> Keep your real bot token private. Never commit `.env` to GitHub.
